CI/CD: Использован GitHub Actions с Self-hosted Runner. Это позволяет автоматически обновлять приложение на сервере сразу после команды git push.

Docker: Использован Multistage Dockerfile.

Stage 1 (Build): Используется образ golang:alpine для сборки бинарного файла. Библиотеки скачиваются через go mod tidy.

Stage 2 (Final): Готовый файл копируется в чистый образ alpine. Это делает итоговый образ очень маленьким и безопасным.

База данных: PostgreSQL установлен прямо на хостовой машине (Ubuntu).

Сеть: Контейнер запущен с флагом --network="host".
